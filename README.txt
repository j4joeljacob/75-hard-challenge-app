PUBLISH WITH GITHUB PAGES
1. Create a public GitHub repository, e.g. 75-hard-tracker.
2. Upload the CONTENTS of this folder to the repository root (index.html, sw.js, manifest.webmanifest, and icons).
3. In repository Settings > Pages, select Deploy from a branch, main, / (root), Save.
4. Visit https://YOUR-USERNAME.github.io/75-hard-tracker/ once GitHub Pages publishes it.
5. On iPhone open the HTTPS URL in Safari, tap Share > Add to Home Screen > Add.
6. Check a box and reopen to verify saving. Data remains on this device/browser; export a backup regularly.
IMPORTANT: Opening the HTML file directly will not install the PWA. Hosting is required.
